flaneur

flaneur lets AI agents running on this computer browse in this Chrome, signed in to the sites you are signed in to.

While this is off, no agent can connect. Turning it off disconnects a connected agent.

Which tabs agents can use

The agent opens its tabs in a window of its own. It cannot see or touch your tabs.

The agent can see, read and control every tab you have open.

Changing this disconnects a connected agent; it connects again with the new choice.
